# Chess Academy

Одностраничный шахматный тренажёр на русском языке. Работает как статический сайт без сборки.

## Возможности

- партия против локального соперника с тремя уровнями сложности;
- проверка легальности ходов и специальных правил через `chess.js`;
- подсказки, учебные позиции, тактические задачи и разбор партии;
- история ходов, экспорт PGN и локальная статистика;
- классические SVG-фигуры, адаптивная доска и пять типов звуковых событий;
- сохранение работоспособности правил и фигур без внешнего CDN.

## Проверка правил

```sh
node tests/chess-rules.test.js
```

Тесты охватывают шах, мат, пат, рокировку, взятие на проходе, превращение пешки и отклонение нелегального хода.

## Источники компонентов

- [chess.js 0.10.3](https://github.com/jhlywa/chess.js/tree/v0.10.3) — проверка шахматных правил.
- [Cburnett chess pieces](https://lichess.org/editor) — классические SVG-фигуры, полученные из набора, используемого Lichess.
